## 🚀 Backend Engineer | NestJS & Node.js Specialist

أهلاً بك! أنا **محمد منصور**، مهندس برمجيات متخصص في بناء أنظمة **Backend** قوية وقابلة للتوسع. أؤمن بقوة **الـTypeScript** في بناء تطبيقات موثوقة، وأركز على تقديم **Clean Code** وأفضل الممارسات في تصميم **الـAPIs** والـ**Microservices**.

- 🎯 **خبرتي الأساسية**: تطوير **RESTful APIs** عالية الأداء، أنظمة **Authentication** متقدمة (JWT، OAuth)، وتصميم بنية **Microservices**.
- 🛠️ **أدواتي في العمل**: **NestJS** (إطار العمل المفضل)، **Express**، و**TypeScript**.
- 💡 **شغف التعلم**: أتعمق حاليًا في **GraphQL** لـAPIs أكثر كفاءة، و**gRPC** للاتصالات الداخلية السريعة، وأستعد لاعتماد **Kubernetes** للـ**Orchestration**.
